Tiny Template Design System

Every visual value in the template resolves through a three-layer token chain. Nothing is hardcoded, and Tailwind's own palette is deleted before the system defines its own. This is the whole vocabulary, read straight out of theme.css.

Architecture

3 layers
Base --interactive-contained-primary-idle-base: 0 90 154;

Space-separated RGB channels, no rgb() wrapper. Redefined in :root and .dark — this is the only layer that changes between modes.

Semantic --color-interactive-contained-primary-idle: rgb(var(--…-base));

Declared once in @theme. Mode-agnostic — it never names a color, only a role.

Utility class="bg-interactive-contained-primary-idle"

Tailwind v4 generates the utility from the @theme entry. This is all product code ever touches.

The triplet in layer 1 is the load-bearing decision. Because the channels are stored unwrapped, any consumer can add an alpha channel at the point of use — bg-elevation-fill-default-1/50 — without a second token existing for the translucent variant. That is why there are 479 base tokens rather than several thousand.

theme.css is generated, not written

The project's own rules say it plainly: "Do not manually edit apps/fe/src/styles/theme.css; it is exported from Figma." All 479 base tokens and the whole @theme block are downstream of the Figma variable set, so the design file is the source of truth and a rename there is what propagates here. Hand-written additions belong in base.css, which loads first and no export overwrites.

Every primitive is deleted first

base.css opens with --color-*: initial, --spacing-*: initial, --radius-*: initial, --text-*: initial, --shadow-*: initial and --breakpoint-*: initial. Tailwind's entire default palette and scale are wiped out before the system defines its own. There is no bg-blue-500 to fall back to — an unbound value fails loudly instead of silently working.

Color

479 tokens · light + dark

Tokens are named for the job they do, never the hue they hold. There is no blue-600 anywhere in the system — the closest thing is interactive-contained-primary-idle, and its value is free to change without a rename. Light and dark are perfectly paired: all 479 names exist in both :root and .dark, with no orphans in either direction.

Typography

2 ramps · 7 weights

The scale is declared twice, in full, under desktop- and mobile- prefixes — a genuine pair of ramps rather than one ramp with fluid clamping. Note that they do not simply shift by one step: title-1 drops 3rem → 1.75rem, while title-5 and title-6 converge on the same 0.875rem on mobile. Label sizes are shared across both.

The real face is General Sans

--font-primary and --font-secondary both resolve to General Sans, loaded from four local .otf files (400/500/600/700). globals.css also imports Inter and Geist as variable fonts, but no token references them — they are available and unused. This page is set in Archivo and Public Sans, because General Sans is not served by Google Fonts and cannot be loaded here; the sizes, line-heights and letter-spacings below are the system's real values.

Overriding a component

Rather than patching CSS at the call site, the template overrides component CVA definitions centrally. apps/fe/src/styles/overrides/ holds nine — button, checkbox, input, label, modal, radio, table, tag and typography — each registered through UIOverrides.defineOverride("tag.cva", …) and applied once at the root. This is the sanctioned escape hatch when a design deviates from the library default.

Mobile

@povio/rn-ui 1.0.0

The React Native app does not share this CSS. It consumes a sibling library, @povio/rn-ui, which ships a Shopify Restyle theme object injected once at the root — the same design decisions expressed as a JS theme rather than custom properties.

Two implementations, one system

Web resolves tokens through Tailwind utilities generated from @theme; mobile resolves them through Restyle's useTheme<Theme>(). Both libraries are versioned separately (3.4.0-rc.12 and 1.0.0), so parity between platforms is a release-discipline question, not something the type system enforces.
